# DVWA Security Labs

Hands-on web application security testing using Damn Vulnerable Web Application (DVWA) in an isolated virtual lab environment.

## Environment

- Kali Linux
- Metasploitable 2
- DVWA v1.0.7
- VirtualBox
- Target: 192.168.56.102
- Network: Isolated local lab

## Labs

### 01 - SQL Injection
Status: Completed

Topics covered:

- Web service enumeration
- HTTP reconnaissance
- Technology identification
- SQL injection discovery
- Input validation testing
- SQL syntax errors
- Tautology-based SQL injection
- Impact assessment
- Security levels in DVWA

### 02 - SQL Injection (Blind)
Status: In progress

Topics covered:

- Blind SQL injection
- Boolean-based SQL injection
- Response analysis
- Input validation testing
- Database behavior analysis
- Security impact assessment
  
## Disclaimer

All testing documented in this repository was performed against intentionally vulnerable applications inside an isolated local virtual lab.

No unauthorized systems were targeted.
